# Python Web Crawler

Web crawler desenvolvido em Python durante meus estudos de programação e cibersegurança.

## Objetivo

O objetivo deste projeto é aprender, na prática, como realizar requisições HTTP, acessar páginas da web e coletar informações utilizando Python.

## Tecnologias

- Python
- Requests
- BeautifulSoup

## O que estou aprendendo

- Requisições HTTP
- Manipulação de URLs
- HTML e DOM
- Extração de informações de páginas
- Web scraping
- Tratamento de erros
- Bibliotecas Python

## Observação

Projeto desenvolvido exclusivamente para fins educacionais.
